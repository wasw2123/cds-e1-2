# 🎯 나만의 파이썬 퀴즈 게임 (Console Quiz Game)

Python과 Git을 활용하여 터미널에서 동작하는 나만의 퀴즈 게임 프로젝트입니다.  
기본적인 파이썬 문법과 객체지향(OOP) 클래스 설계, JSON 파일 저장(데이터 영속성), 그리고 Git/GitHub을 통한 버전 관리까지 직접 구현하며 학습합니다.

---

## 📌 프로젝트 개요
- **개발 언어**: Python 3.10+ (표준 라이브러리만 사용)
- **데이터 저장**: `state.json` (UTF-8 인코딩)
- **버전 관리**: Git & GitHub

## 💾 데이터 파일 설명 (`state.json`)
프로그램을 종료해도 데이터가 유지될 수 있도록 프로젝트 루트의 `state.json`에 데이터를 저장합니다.

### 데이터 스키마 (Schema)
```json
{
  "quizzes": [
    {
      "question": "Python의 창시자는 누구일까요?",
      "choices": ["Guido van Rossum", "Linus Torvalds", "Bjarne Stroustrup", "James Gosling"],
      "answer": 1
    }
  ],
  "best_score": 0
}
```
